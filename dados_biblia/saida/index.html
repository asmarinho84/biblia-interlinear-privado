Como ler

Cada palavra é uma coluna com quatro linhas: original · transliteração · glosa em português (sentido do dicionário, em forma de lema; ver abaixo quando o contexto escolheu outro sentido) · morfologia. Glosas ligadas por hífen são morfemas da mesma palavra (e-o-céu, semente-dele). (pl)/(du) = plural/dual. Pessoa, gênero, número, tempo e demais traços estão na linha morfológica: 3ms = 3ª pessoa masc. sing.; sg/pl/du = singular/plural/dual; abs/cst/det = estado absoluto/construto/determinado. Passe o cursor (ou toque) sobre a palavra para ver todos os sentidos do dicionário. As glosas vêm de dicionários (OpenScriptures HebrewLexicon e MorphGNT lexicon, traduzidos para o português), não de outra Bíblia.

Sentido escolhido pelo contexto: palavras com sublinhado pontilhado tiveram o sentido escolhido entre os do dicionário conforme o contexto (toque para ver o motivo): A = a forma gramatical (tema verbal, caso, gênero, número) decide; B = escolha pelo contexto entre os sentidos do dicionário; C = locução de duas ou mais palavras. Substantivos hebraicos em construto levam “-de” (palavra-de); pronomes gregos seguem o caso (dele, a-ele).
